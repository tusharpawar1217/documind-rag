MIGRATION MAPPING:
==================

1. ingestion/loader.py:
   - PDF parsing from app/utils/pdf_parser.py
   - File storage from app/services/storage.py
   - Vision processing from app/services/vision_processor.py

2. chunking/chunker.py:
   - SemanticChunker from app/utils/text_processing.py
   - Token counting utilities

3. embeddings/embedder.py:
   - embed_text() from app/services/gemini_client.py
   - embed_batch() from app/services/gemini_client.py

4. vectordb/vector_store.py:
   - QdrantService from app/services/qdrant_client.py
   - All vector operations

5. retrieval/retriever.py:
   - HybridSearch from app/services/hybrid_search.py
   - BM25 from app/utils/bm25.py

6. prompts/prompt_templates.py:
   - Extract prompt templates from app/services/response_generator.py
   - System prompts, user prompts

7. llm/llm_client.py:
   - generate_text() from app/services/gemini_client.py
   - Chat functionality

8. api/routes.py:
   - All routes from app/api/
   - FastAPI app initialization from app/main.py

9. utils/helpers.py:
   - Config loading (from app/core/config.py)
   - Logging setup (from app/core/logging_config.py)
   - Validators (from app/utils/validators.py)
   - Security (from app/core/security.py)
